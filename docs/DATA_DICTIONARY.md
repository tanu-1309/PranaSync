## Document store (its own database, `DOCSTORE_URL`)

One row per upload. The columns below are plain so the store can list and sort without opening anything; the JSON document is sealed (AES-256-GCM, one key per person).

| Column | Type | Notes |
|---|---|---|
| `doc_id` | VARCHAR | plain |
| `patient_id` | VARCHAR | plain |
| `uploaded_at` | VARCHAR | plain |
| `updated_at` | VARCHAR | plain |
| `status` | VARCHAR | plain |
| `sealed` | TEXT | sealed JSON document |

### The sealed JSON document

| Field | Contents | Stored |
|---|---|---|
| `doc_id, patient_id` | ids of the document and its owner | plain |
| `version` | schema version (1) | plain |
| `status` | needs_review or confirmed | plain |
| `source` | filename, size_bytes, type, sha256, kind | sealed |
| `uploaded_at, extracted_at, reviewed_at` | ISO times in UTC | sealed |
| `extracted_text` | the text the values were read from (up to 200,000 characters) | sealed |
| `notes` | messages from the reader (for example 'read from a picture') | sealed |
| `values[]` | param, label, unit, value, original_value, text, kind, choices, min, max, source_text, observed_on, edited, ignored, read_by (patterns, AI or image) | sealed |
| `edit_history[]` | at, param, label, from, to for every correction or set-aside | sealed |
| `extraction` | method and which parameters the AI second reader added | sealed |

## Unit conversions (src/prana/risk/extract.py)

| From | To | Rule |
|---|---|---|
| fasting glucose mmol/L | mg/dL | x 18.016 |
| LDL, HDL, total cholesterol mmol/L | mg/dL | x 38.67 |
| triglycerides mmol/L | mg/dL | x 88.57 |
| HbA1c mmol/mol | % | x 0.09148 + 2.152 |
| height cm or m, weight kg or lb | BMI kg/m2 | weight / height squared |
| decimal comma (6,1) | decimal point (6.1) | one or two digits after the comma; three digits is a thousands separator |
